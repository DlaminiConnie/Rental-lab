What it can do

Landlord Dashboard** - View all properties, rooms and tenants
Tenant Management** - Add, view and manage tenants
Rooms** - Track rooms, availability and pricing
Transactions** - Record rent payments and history
Login / Auth** - Secure login for users

Tech Used

- Python + Django
- HTML, CSS, Bootstrap
- SQLite Database
- Git & GitHub

 How to run it on your computer

1. Clone the repo:
   git clone https://github.com/DlaminiConnie/Rental-lab.git

2. Go into the folder:
   cd Rental-lab

3. Install requirements:
   pip install -r requirements.txt

4. Run the server:
   python manage.py runserver

5. Open in browser:
   http://127.0.0.1:8000/
